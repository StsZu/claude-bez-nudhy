# Бот-нагадувач «Claude без нудьги»

Telegram-бот: раз на день в обраний час (за Києвом, лише 07:00–21:59) надсилає одну місію на 5 хвилин з посиланням на сайт і кнопкою «Міні-квіз». Серія днів рахується за тими ж правилами, що й на сайті (`GAME_DESIGN.md`). Після 3 днів без реакції бот надсилає одне повідомлення й ставить нагадування на паузу.

Команди: `/start` — привітання й вибір часу · `/time 07:30` — свій час · `/today` — місія зараз · `/stop` — вимкнути нагадування · `/forget` — видалити всі дані.

## Встановлення й тести

Потрібен [uv](https://docs.astral.sh/uv/) і Python 3.12.

```bash
cd bot
uv sync --extra dev
uv run --extra dev pytest -q
```

Тести не потребують токена й мережі: курс береться з `tests/fixtures/course.json`.

## Звідки бот бере уроки

`COURSE_JSON` — шлях або URL до `course.json`, який генерує сайт (`/course.json`, контракт — `specs/001-interactive-course/plan.md`). Остання вдала копія зберігається у `COURSE_CACHE_PATH`; якщо джерело недоступне, бот працює з нею. Курс перечитується раз на годину.

## Запуск — лише з дозволом власника

> Живий запуск потребує рішення D2 у `specs/001-interactive-course/spec.md`: токен і хостинг. Нічого з переліченого нижче не робиться без явного дозволу власника.

1. Отримати токен у [@BotFather](https://t.me/BotFather) (`/newbot`).
2. `cp .env.example .env` і заповнити `BOT_TOKEN`, `SITE_URL`, `COURSE_JSON`. Файл `.env` не потрапляє в git — не комітити токен.
3. Перевірити локально: `uv run --env-file .env python -m bez_nudhy_bot.main`.
4. Розмістити на сервері, що працює 24/7 (VPS або домашній сервер, $0–5/міс), запуском тієї ж команди як сервісу (systemd, Docker тощо). Файл бази (`DB_PATH`) має лежати на постійному диску.

Дані: бот зберігає лише `chat_id`, обраний час, дати останнього повідомлення й реакції, серію, пройдені уроки та відповіді квізу. `/forget` видаляє рядок повністю.
