## Чотири рівні автопілота

- **Без коду** — задача за розкладом у застосунку Claude (платні плани). Приклад: щопонеділка о 9:00 — зведення листів і зустрічей на тиждень.
- **Трохи коду** — Make, Zapier, n8n. Прийшов лист з рахунком → дані в таблицю → повідомлення в Slack.
- **Код** — Claude API, Agent SDK. Бот підтримки або обробка 10 000 PDF щоночі.
- **Код у команді** — Claude Code у GitHub Actions. Автоматичне рев'ю кожного pull request.

## Що треба знати про API

API **оплачується окремо від підписки**, за обсяг тексту (токени).

Ті самі моделі доступні й через Amazon Bedrock, Google Vertex AI та Microsoft Foundry.

<details><summary>Для розробників: найкоротший старт (Python)</summary>

```python
import anthropic

client = anthropic.Anthropic()  # ключ з ANTHROPIC_API_KEY
msg = client.messages.create(
    model="claude-sonnet-5-5",
    max_tokens=1024,
    messages=[{"role": "user", "content": "Підсумуй цей звіт: ..."}],
)
print(msg.content[0].text)
```
