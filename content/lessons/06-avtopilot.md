## Чотири рівні автоматизації

Від найпростішого до найскладнішого:

- **Без коду.** Задача за розкладом у застосунку Claude (платні плани). Приклад: щопонеділка о 9:00 Claude робить зведення листів і зустрічей на тиждень.
- **Трохи коду.** Сервіси Make, Zapier, n8n з'єднують програми в ланцюжок. Приклад: прийшов лист з рахунком → дані потрапили в таблицю → у Slack з'явилось повідомлення.
- **Код.** Claude API та Agent SDK — інструменти для програмістів. Приклад: бот підтримки або обробка 10 000 PDF щоночі.
- **Код у команді.** Claude Code у GitHub Actions — автоматичних діях на GitHub. Приклад: Claude переглядає кожну запропоновану зміну в коді (pull request).

## Що таке API і скільки він коштує

API — це спосіб підключити Claude до своєї програми чи бота.

API **оплачується окремо від підписки**. Платиш за обсяг тексту, який обробив Claude. Цей обсяг рахують у токенах — це шматочки слів.

Ті самі моделі доступні й через хмарні сервіси Amazon Bedrock, Google Vertex AI та Microsoft Foundry.

<details><summary>Для розробників: найкоротший старт (Python)</summary>

```python
import anthropic

client = anthropic.Anthropic()  # ключ з ANTHROPIC_API_KEY
msg = client.messages.create(
    model="claude-sonnet-5-5",
    max_tokens=1024,
    messages=[{"role": "user", "content": "Підсумуй цей звіт: ..."}],
)
print(msg.content[0].text)
```
