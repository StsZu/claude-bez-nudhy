## Чим це відрізняється від чату

**Звичайний чат** — як друг, якому ти диктуєш код по телефону. Ти сам копіюєш код у чат і назад.

**Claude Code** — як стажер, що сидить за твоїм комп'ютером. Він сам знаходить потрібні файли, змінює їх і запускає команди.

## Де він працює

Це той самий Claude Code у різних місцях:

- у **терміналі** (вікні для текстових команд) — команда `claude`;
- у редакторах коду: VS Code, PyCharm та інших редакторах JetBrains;
- на вкладці Code у програмі Claude на комп'ютері;
- у браузері й на телефоні: даєш задачу, і вона виконується, поки ти робиш інше.

**Важливо:** потрібен платний план або API-ключ.

## Що можна попросити

- «Чому цей скрипт падає? Знайди причину й виправ.»
- «Перейменуй цю змінну в усьому проєкті так, щоб нічого не зламалось.»
- «Напиши тести, які я відкладаю пів року.» Тести — це маленькі програми, що перевіряють, чи працює код.
