# Claude без нудьги — інтерактивний курс

8 місій по 5 хвилин про те, як працювати з Claude там, де вже лежать твої дані. Для команди, без реєстрації, з XP, бейджами, сюжетом «214 листів» і нагадуваннями. Прогрес зберігається на пристрої учня.

| Тека | Що там |
|---|---|
| `content/` | **Текст курсу** — редагується без програмування |
| `web/` | Сайт курсу (Astro, статичний) |
| `bot/` | Telegram-бот нагадувань (Python) — див. `bot/README.md` |
| `GAME_DESIGN.md` | Сюжет, XP, рівні, бейджі, серія днів, план нагадувань |
| `NEEDS_REVIEW.md` | Факти, які треба перевірити перед запуском |
| `course/course.md` | Вихідний текст курсу (джерело фактів) |
| `specs/001-interactive-course/` | Специфікація, план, завдання, аудит, докази |

## Як змінити урок (для нетехнічної людини)

Кожен урок — один файл у `content/lessons/`, наприклад `02-chat.md`. Відкрий його в будь-якому текстовому редакторі (TextEdit у режимі «простий текст», Блокнот, VS Code).

Файл має дві частини:

1. **Шапка** — між двома рядками `---` угорі. Тут назва, «головне», квіз і дія.
   - `title:` — назва уроку; `mission:` — назва місії; `tldr:` — «головне» (1–3 прості речення); `hook:` — сюжетний вступ.
   - `quiz:` — рівно 3 питання. У кожного: `q:` питання, `options:` 2–4 варіанти, `answer:` номер правильного варіанта **рахуючи з 0** (перший = 0, другий = 1), `why:` пояснення, яке учень бачить одразу.
   - `action:` — `text:` що зробити за 2 хвилини, `prompt:` промпт для кнопки «Скопіювати».
   - Якщо текст містить двокрапку `:`, візьми його в лапки: `title: "Чат: швидкий старт"`.
   - Відступи (пробіли на початку рядка) важливі — копіюй їх з сусідніх рядків.
2. **Картки** — усе після шапки. Кожен заголовок `## Назва` починає нову картку (1–3 картки на урок). Текст — звичайний Markdown: `**жирний**`, списки з `- `.

**Крок за кроком:**

1. Відкрий файл уроку й зміни текст.
2. Збережи файл.
3. Перевір: у Терміналі в теці `web` виконай `npm run dev` і відкрий http://localhost:4321/lesson/2/ (номер — твого уроку). Зміни видно після оновлення сторінки.
4. Якщо щось не так у шапці, у Терміналі буде повідомлення українською: який файл і яке поле виправити.
5. Перевір довжину й слова: `npm run check:content` (урок ≤ 450 слів).

Челендж — `content/challenge.yaml`, шпаргалка «Які двері» — `content/doors.yaml`. Числа XP і бейджі — у `GAME_DESIGN.md` і `web/src/lib/game.ts` (це вже код).

**Факти про продукти Claude** додавай лише з офіційних сторінок, з датою перевірки. Сумнівне — у `NEEDS_REVIEW.md`, не в урок.

## Як запустити локально

Потрібно: Node.js 22+ (перевірено на 26).

```bash
cd web
npm install
npm run dev          # http://localhost:4321, оновлюється при змінах
```

Перевірки:

```bash
npm test             # логіка гри, сховище, календар, контент (Vitest)
npm run check:content
npm run e2e          # сценарії в Chrome на 360 px (Playwright; збирає й запускає сайт сам)
npm run build && npx astro preview --background && npm run lighthouse && npx astro preview stop
```

Playwright використовує встановлений Google Chrome (`channel: 'chrome'`), окремо браузери не завантажує.

## Як задеплоїти (після підтвердження власника)

Сайт — звичайні статичні файли з `web/dist/`. Підходить будь-який статичний хостинг за $0.

- **GitHub Pages (обрано):** готовий workflow `.github/workflows/pages.yml`. Один раз: у репозиторії Settings → Pages → Source: **GitHub Actions**. Далі кожен push у `main` проганяє тести, перевірку контенту й публікує сайт; адресу й підшлях workflow бере сам. Ручна збірка: `SITE_URL=https://<user>.github.io BASE_PATH=/<repo>/ npm run build`.
- **Netlify / Vercel:** тека збірки `web`, команда `npm run build`, тека публікації `dist`; задати `SITE_URL`.

На GitHub `PUBLIC_UMAMI_WEBSITE_ID` задано як змінну репозиторію (Settings → Secrets and variables → Actions → Variables); workflow передає її в збірку. Це не секрет — ID видно в коді сторінки.

Змінні середовища (файл `web/.env`, не в git):

| Змінна | Навіщо |
|---|---|
| `SITE_URL` | Повна адреса сайту (для посилань у `course.json` і календарі) |
| `BASE_PATH` | Підшлях, якщо сайт не в корені домену |
| `PUBLIC_UMAMI_WEBSITE_ID` | Вмикає аналітику Umami; без неї жодних запитів аналітики |
| `PUBLIC_UMAMI_SRC` | Адреса скрипта Umami, якщо self-host |
| `PUBLIC_TELEGRAM_BOT` | Ім'я бота без `@` — з'явиться посилання на сторінці «Нагадування» |

Бот бере уроки з `https://<сайт>/course.json` (змінна `COURSE_JSON` у `bot/.env`).

## Аналітика

Події: `lesson_start`, `card_view` (відсів по картках), `quiz_answer`, `action_done`, `lesson_complete`, `challenge_day`, `reminder_set`. Без персональних даних — лише номери уроків, карток і питань. Метрика успіху: частка пристроїв з `lesson_start` для уроку 1, що дійшли до `lesson_complete` уроку 8 за 14 днів (мета ≥ 60%).
