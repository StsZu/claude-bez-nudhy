# План: «Claude без нудьги — інтерактивний курс»

Джерела: `spec.md`, `../../.specify/memory/constitution.md` 1.0.0, `../../GAME_DESIGN.md`.

## Короткий пакет погодження

- Ідея: 8 місій по 5 хв з квізами, нагородами, сюжетом і нагадуваннями, щоб команда дійшла до кінця курсу.
- Рекомендація: **Продовжити** — платформа D поетапно: статичний вебкурс + календарне нагадування; бот — код і тести, запуск після токена.
- Обсяг / поза обсягом: FR-01…FR-21; поза — акаунти, синхронізація, web-push, рейтинги, деплой без дозволу (див. `spec.md` → «Межі»).
- Істотні припущення: A1–A6 у `spec.md`.
- Потрібні рішення: D1 хостинг, D2 бот (токен + хостинг), D3 аналітика — блокують лише зовнішні дії, не реалізацію.
- Хвилі: W1 фундамент → W2 P1 (урок 1 + карта) → W3 P2 (гра, довідники, нагадування) → W4 бот → W5 якість → W6 передача.

**Рекомендація: D поетапно.** Гіпотезу власника підтверджено з уточненням: зовнішній тригер першої лінії — календарний файл (0 серверів, 0 токенів, працює в будь-якому календарі, вимикається видаленням подій), бот — друга лінія для тих, хто живе в Telegram. Обидва беруть уроки з одного джерела (`content/lessons`).
**Слабкі місця D:** (1) прогрес вебу й бота не синхронізується — два окремі лічильники; (2) бот потребує сервера 24/7 і токена — без рішення D2 він не працює; (3) немає акаунтів, тому метрика SC-08 рахує пристрої, а не людей; (4) для платного курсу знадобиться переробка (акаунти, оплата) — тоді B стане дешевшим за часом.

## Підхід і контракти

| Рішення | Чому | Альтернативи |
|---|---|---|
| Astro 5 (статичний вивід) + TypeScript-скрипти без фреймворку | HTML з сервера, мінімум JS → Perf ≥ 90; без JS курс читається (FR-20) | React islands — +40 КБ JS без потреби; vanilla SPA як `claude-academy-uk` — немає валідації контенту на збірці |
| Контент: `content/lessons/NN-slug.md` — шапка YAML (квіз, дія, демо) + Markdown-картки, розділені `## ` | Нетехнічна людина редагує текст; схема шапки перевіряється на збірці (FR-18) | MDX — компоненти в тексті, легко зламати; JSON — незручно для довгого тексту |
| Схема шапки — content collections + zod з людськими повідомленнями | Помилка називає файл і поле | Ручна перевірка скриптом — дублювання |
| Логіка гри — чисті функції `web/src/lib/game.ts` з датою як аргументом | Тестується Vitest без браузера; той самий алгоритм портується в Python | Логіка в обробниках DOM — нетестована |
| Сховище — `localStorage` (ключ `bez-nudhy:v1`) через обгортку з try/catch і запасом у пам'яті | Вимога TASK; FR-10 | IndexedDB — складніше без потреби |
| Нагадування — генерація `.ics` у браузері (Blob) | 0 серверів; RFC 5545 | Web-push — потрібен сервер і дозвіл, ризик dark pattern |
| `course.json` — статичний ендпойнт Astro (`/course.json`) | Єдине джерело для бота | Бот парсить Markdown сам — дублювання парсера |
| Бот — Python 3.12, aiogram 3, stdlib `sqlite3`, цикл розсилки раз на хвилину, `zoneinfo` Europe/Kyiv | Вимога TASK; мінімум залежностей | APScheduler — зайва залежність для одного щохвилинного циклу |
| Аналітика — Umami через `track(name, data)`; скрипт підключається лише якщо задано `PUBLIC_UMAMI_WEBSITE_ID` | FR-17, приватність, $0 | Plausible — від $9/міс у хмарі |
| Шрифт — системний стек, базовий розмір 18 px, рядок 1.6 | Без зовнішніх запитів (Perf), кирилиця гарантована | Atkinson Hyperlegible — немає певності щодо кирилиці, +запит |
| Тести: Vitest (логіка), Playwright з встановленим Chrome (`channel: 'chrome'`), Lighthouse CLI | Без завантаження браузерів | Завантаження Chromium — +150 МБ |

**Контракт `course.json`** (версія 1):
```json
{ "version": 1, "site": "<базовий URL>",
  "lessons": [{ "id": 1, "slug": "odna-holova", "title": "…", "mission": "…", "tldr": "…",
                "minutes": 5, "url": "/lesson/1/",
                "quiz": [{ "q": "…", "options": ["…"], "answer": 0, "why": "…" }],
                "action": { "text": "…", "prompt": "…" } }],
  "challenge": [{ "day": 1, "text": "…", "lesson": 2 }] }
```

**Події аналітики:** `lesson_start {lesson}`, `card_view {lesson, card, kind}` (відсів по екранах), `quiz_answer {lesson, q, correct, first}`, `action_done {lesson}`, `lesson_complete {lesson}`, `challenge_day {day}`, `reminder_set {channel}`. D1/D7 retention — звіт Retention в Umami за унікальними відвідувачами.

## Перевірка конституції

- До дизайну: усі рішення в межах $0, без акаунтів і серверів для веба; NN-03 — `.env` у `.gitignore`, деплой і токени винесено в D1–D3.
- Після дизайну: NN-02 — `game.ts` не має операцій, що зменшують XP/бейджі (перевіряють unit-тести); NN-04 — квіз показує пояснення в тому ж обробнику, що й результат; NN-05 — картки рендеряться на сервері, JS лише приховує неактивні. Відхилень немає.
