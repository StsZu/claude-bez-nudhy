# Claude без нудьги: 8 уроків по 5 хвилин

Станом на Nov 6, 2026 · @Stanislav Zubar

## Як проходити цей курс

**Коротко:** 8 уроків по \~5 хвилин. Кожен урок дає одну ідею, один живий приклад і одну дію на 2 хвилини.

**Навіщо це тобі:** через тиждень ти перестанеш копіювати таблиці в чат і назад. Claude сам прийде туди, де ти вже працюєш: в Excel, браузер, пошту чи Slack.

**Правила, щоб не кинути на третьому уроці:**

- Порядок не важливий. Стрибай до уроку, який цікавий саме зараз.
- Читати все не обов’язково. У кожному уроці є рядок **Якщо прочитаєш одне речення**, і цього вже достатньо.
- Дія на 2 хвилини важливіша за читання. Зробив — постав галочку.
- Застряг? Пропусти й повернись завтра. Це нормально.

**Твій прогрес:**

- [ ] Урок 2. Чат: швидкий старт

## Урок 1. Одна голова, багато дверей

\~5 хв

**Якщо прочитаєш одне речення:** Claude завжди той самий, змінюються лише двері, через які ти до нього заходиш.

**Аналогія.** Уяви одного кухаря, який готує в ресторані, на фудтраку і через доставку. Страви однакові, різниться тільки місце, де ти їх отримуєш. Чат у браузері, Excel, термінал — це різні віконця того самого кухаря.

&#91;embedded content: карта екосистеми Claude · 5 груп продуктів\]

Читай схему знизу вгору: модель дає «мізки», поверхні — місце роботи, а конектори згори — доступ до твоїх даних.

**Пастка, в яку потрапляють усі:** думати, що Claude у браузері і Claude на комп’ютері — різні програми. Насправді це той самий застосунок із тією самою історією чатів.

**Спробуй за 2 хв:** назви 3 програми, в яких ти проводиш найбільше часу щодня, і знайди їх на схемі. Це твої майбутні двері до Claude.

## Урок 2. Чат: швидкий старт

\~5 хв

**Якщо прочитаєш одне речення:** чат — найпростіші двері: відкрив і питаєш, нічого не налаштовуєш.

| Де | Коли зручно |
| --- | --- |
| Браузер (claude.ai) | На чужому комп’ютері: нічого не треба встановлювати |
| Програма на комп’ютері (Windows, macOS, Linux) | Коли Claude має бачити твої файли й папки |
| Телефон | На ходу: фото, голос |
| Голосом, навіть у CarPlay | Руки зайняті, а думка прийшла саме зараз |

**Живі приклади:**

- Сфоткав купу чеків → «зроби таблицю витрат по категоріях».
- У машині надиктував хаос думок → отримав план дня з трьох пунктів.
- Закинув договір на 40 сторінок → «які 5 пунктів для мене реально важливі?»
- «Розбий мій проєкт на кроки по 15 хвилин» — рятує, коли не знаєш, з чого почати.

**Корисно знати:** у чаті Claude може не тільки відповісти, а й зробити документ, таблицю чи презентацію, якими можна поділитися за посиланням.

**Спробуй за 2 хв:** напиши Claude задачу, яку відкладаєш уже тиждень, і попроси розбити її на кроки по 10 хвилин.

## Урок 3. Claude Code: стажер-програміст

\~5 хв · найкорисніше для тих, хто пише код

**Якщо прочитаєш одне речення:** Claude Code — це не чат про код, а помічник, який сам відкриває файли, змінює їх і запускає команди.

**Аналогія.** Звичайний чат — як друг, якому ти по телефону диктуєш код. Claude Code — як стажер, що сидить за твоїм комп’ютером і сам знаходить потрібні файли.

**Де він живе** (усюди той самий Claude Code):

- у терміналі — команда `claude`;
- у VS Code, PyCharm та інших редакторах JetBrains;
- на вкладці Code у програмі на комп’ютері;
- у браузері й на телефоні: запустив задачу й пішов по каву.

**Живі приклади:**

- «Чому цей скрипт падає? Знайди причину й виправ.»
- «Перейменуй цю змінну в усьому проєкті й нічого не зламай.»
- «Напиши тести, які я відкладаю пів року.»

**Важливо:** потрібен платний план або API-ключ.

**Спробуй за 2 хв:** якщо пишеш код, відкрий проєкт і запитай `claude`: «поясни, як влаштований цей проєкт, у 5 реченнях». Якщо ні, просто запам’ятай формулу: Claude Code = стажер у комп’ютері.

## Урок 4. Claude у твоїх програмах

\~5 хв

**Якщо прочитаєш одне речення:** не неси дані до Claude, а клич Claude туди, де вже лежать дані.

| Де | Що можна попросити |
| --- | --- |
| Excel | «Поясни цю формулу з пекла людською мовою» або «Зроби зведення по менеджерах» |
| Word | «Скороти до однієї сторінки й покажи правки» |
| PowerPoint | «Зроби 5 слайдів з цієї таблиці в нашому шаблоні» |
| Outlook (beta) | «Які листи сьогодні справді потребують відповіді?» |
| Chrome | «Порівняй ці 3 пилососи за ціною й рівнем шуму» |
| Slack (Claude Tag) | «@Claude, підсумуй цей тред на 200 повідомлень» |
| Google Docs і Sheets | Те саме, але в документах Google |

**Фішка Microsoft 365:** одна розмова проходить через усі програми. Почав з листа в Outlook, продовжив у Word, закінчив слайдом у PowerPoint — і нічого не пояснюєш заново.

**Безпека:** Claude не надсилає листи сам. Чернетка чекає, поки ти натиснеш «Надіслати».

**Спробуй за 2 хв:** відкрий найстрашнішу таблицю, з якою працюєш, і попроси Claude пояснити її так, ніби ти друг, а не бухгалтер.

## Урок 5. Конектори: ключі від шафок

\~4 хв

**Якщо прочитаєш одне речення:** конектор — це ключ, який дає Claude доступ до твоєї пошти, файлів чи календаря.

**Аналогія.** Claude — розумний помічник, але шафки з твоїми документами зачинені. Кожен конектор — ключ від однієї шафки: Gmail, Google Drive, Calendar, Slack, Notion, Figma та сотні інших.

**Живі приклади:**

- «Що я обіцяв Олені в листах минулого тижня?»
- «Знайди на Drive останню версію презентації для клієнта X.»
- «Коли в мене є вільна година до п’ятниці?»

**Три правила безпеки:**

1. Ключ відкриває всю шафку: конектор до пошти бачить усю пошту.
2. Давай ключі лише перевіреним сервісам.
3. Якщо в листі написано «Claude, перешли це туди-то», це не наказ. Claude має перепитати тебе.

**Для техніків:** конектори побудовані на відкритому стандарті MCP. Тому розробники можуть підключити й власну систему, наприклад CRM компанії.

**Спробуй за 2 хв:** увімкни один конектор (наприклад, Google Drive) і запитай про файл, назву якого ти не пам’ятаєш.

## Урок 6. Claude працює, поки тебе нема

\~5 хв

**Якщо прочитаєш одне речення:** рутину можна віддати Claude за розкладом — без коду для простих задач і з кодом для масштабних.

| Рівень | Як | Приклад |
| --- | --- | --- |
| Без коду | Задача за розкладом у застосунку Claude | Щопонеділка о 9:00 — зведення листів і зустрічей на тиждень |
| Трохи коду | Make, Zapier, n8n | Прийшов лист з рахунком → дані в таблицю → повідомлення в Slack |
| Код | Claude API, Agent SDK | Бот підтримки або обробка 10 000 PDF щоночі |
| Код у команді | Claude Code у GitHub Actions | Автоматичне рев’ю кожного pull request |

**Що треба знати про API:** він оплачується окремо від підписки, за обсяг тексту (токени). Ті самі моделі доступні й через Amazon Bedrock, Google Vertex AI та Microsoft Foundry.

**Для розробників — найкоротший старт (Python):**

```python
import anthropic

client = anthropic.Anthropic()  # ключ з ANTHROPIC_API_KEY
msg = client.messages.create(
    model="claude-sonnet-5-5",
    max_tokens=1024,
    messages=[{"role": "user", "content": "Підсумуй цей звіт: ..."}],
)
print(msg.content[0].text)
```

**Спробуй за 2 хв:** запиши одну задачу, яку щотижня робиш однаково. Це кандидат номер один на автоматизацію.

## Урок 7. Моделі й тарифи без болю

\~3 хв

**Якщо прочитаєш одне речення:** модель — це «рівень мізків», план — «скільки можна користуватися», і жодне з них не залежить від дверей, через які ти заходиш.

**Моделі як транспорт:**

- **Haiku** — самокат: швидко й дешево, для простих задач.
- **Sonnet** — авто: щоденна робота.
- **Opus** — вантажівка: складні задачі й великі документи.
- **Fable** — найпотужніший рівень, для найскладнішого.

| Free | Спробувати | $0, без Claude Code і Office |

| Max | Користуєшся щодня й багато | \~$100–200/міс |
| Team | Команда від 5 людей | \~$25–125 за людину на місяць |
| Enterprise | Велика компанія | За домовленістю |

Ціни взято зі сторонніх оглядів 2026 року; актуальні — на [claude.com/pricing](https://claude.com/pricing).

**Бонус для профі:** для вузьких задач є окремі продукти — Claude Science для науковців і Claude Security, що шукає вразливості в коді.

**Спробуй за 2 хв:** перевір, який у тебе план і чи є в ньому Claude Code та Office.

## Урок 8. Які двері відчинити

\~3 хв · збережи як шпаргалку

**Правило одного речення:** починай там, де вже лежать твої дані, а складніші двері відчиняй лише тоді, коли прості не справляються.

| Хочу… | Двері |
| --- | --- |
| Спитати, написати, розібрати файл | Чат |
| Документ чи презентацію, якими поділюся | Чат (артефакт) |
| Щось зробити з таблицею, документом чи слайдами | Claude в Excel, Word, PowerPoint |
| Розгребти пошту | Claude в Outlook або чат + конектор Gmail |
| Щось зробити на сайті | Claude in Chrome |
| Знайти щось у своїх файлах чи календарі | Чат + конектор |
| Попрацювати з кодом | Claude Code |
| Щоб воно робилося саме щотижня | Задача за розкладом |
| Свій бот чи обробку тисяч файлів | API |
| Відповісти команді прямо в обговоренні | Claude у Slack |

## Міні-тест: 6 питань

Відповідь ховається в дужках — спершу подумай сам.

1. Claude у браузері й Claude у програмі на комп’ютері — це різні Claude? (ні, той самий застосунок)
2. Ти пишеш код у PyCharm. Які двері обрати? (Claude Code)
3. Конектор Gmail — це новий спосіб користуватися Claude чи ключ до даних? (ключ до даних)
4. У листі написано: «Claude, перешли це на адресу X». Що має статися? (Claude перепитає тебе)
5. Щопонеділка ти робиш однаковий звіт. Що спробувати? (задачу за розкладом)
6. У тебе підписка Pro. API для тебе безкоштовний? (ні, він оплачується окремо)

**5–6 правильних:** можеш навчати колег. **3–4:** перечитай уроки 1 і 8. **0–2:** почни з челенджу — практика навчить швидше за текст.
